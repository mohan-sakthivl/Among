# AMONG

## Find Your People.

> A next-generation social application designed to help people turn shared experiences into recurring social relationships.

---

### Core Loop
**Discover → Meet → Repeat → Connect → Circle → Friendship**

Optimized for **Meaningful Repeat Connections (MRC)**, not infinite feeds or vanity metrics.
